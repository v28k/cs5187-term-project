\paragraph{The last report.} BUG \#19826 (\texttt{corr()}, \texttt{regr\_r2()},
\texttt{regr\_slope()} of a constant input differ under partial aggregation, a
regression from commit \texttt{649828769}; plan-variant oracle): Tom Lane reviewed our patch and revised it with us; our v4 was committed as \texttt{ef1b7404} (12 November, back-patched to 19); all versions are in \file{docs/bughunt/new/}. For BUG
\#19766 (an assertion in \texttt{shm\_toc\_insert}, reported by someone else) we
found the bug independently and posted a reproducer with inheritance tables.

\paragraph{Duplicates our oracles found.} \#19800 (plan variant: self-join
elimination on and off), \#19772 (\texttt{e} against \texttt{(SELECT e)}),
and \#19784. Each one confirms that the oracle works on a real bug, even though
someone else reported it first. The campaigns also rediscovered our own \#19771.

\paragraph{Rediscovery.} Every reproducer is a seed in
\file{src/corpus/bug_seeds/}, and a seed may declare the check that recognises
its wrong result. One 150-second trial of the Grammar+Oracles configuration on
the base build \texttt{26bd08fb} reports all ten bugs, each matched to its
catalogue entry (\file{src/known_bugs/known_bugs.yaml}); for this short run the seeds are replayed
in turn. The bugs fixed
before the base build was made still reproduce, because \texttt{26bd08fb}
predates their fixes. Command: \texttt{sudo bash scripts/reproduce.sh}.
Output on 13 November 2026: ``Known bugs reproduced: 10 of 10''.
After one of the expected assertion crashes, crash recovery can fail because of a known
bug (BUG \#17731, ``could not create file \dots: File exists''); the server script then
starts a new cluster and the fuzzer recreates its schema.

\section{How a bug goes from candidate to report}

\begin{enumerate}
  \item The oracle marks a test case (crash, assertion, internal error, hang,
    or two equivalent queries with different results) and the harness saves it
    with its signature.
  \item Triage re-runs it three times (flaky if not every time), reduces it on
    the derivation tree and then on tokens, and localizes it to a planner
    setting, a rewrite or a version.
  \item A person decides the verdict (real, duplicate, false positive, not a
    bug, flaky) in \file{triage/verdicts.yaml}; a false positive becomes a
    soundness fix with a test.
  \item For a real bug: re-check on the newest master and stable branches,
    search the archives for duplicates, write the root cause, a patch and a
    regression test, then report through the \pg bug form or the mailing list.
\end{enumerate}
