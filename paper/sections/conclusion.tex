\section{Conclusion}
\label{sec:conclusion}

Wrong results are the bugs of a database system that users cannot see. Of 23
recent fixes in \pg query processing, 20 change what a query returns and only
9 of them crash or raise an internal error. We presented \tool, which
generates SQL as typed derivation trees, rewrites those trees to build
metamorphic checks, compares each query with its plan variants and with the
last release, and extends its grammar from recent commits with an LLM whose
proposals a validation gate checks on the server. \tool found two previously
unknown bugs in \pg and \num{RQ1--RQ4 summary, same numbers as the abstract}.
The precision of the oracles, not the reach of the generator, decided how
useful its findings were.
