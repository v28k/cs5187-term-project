\section{Conclusion}
\label{sec:conclusion}

Wrong results are the bugs of a database system that users cannot see. Of 23
recent fixes in \pg query processing, 20 change what a query returns and only
9 of them crash or raise an internal error. We presented \tool, which
generates SQL as typed derivation trees and rewrites those trees to build
metamorphic checks. It compares each query with its plan variants and with
the last release, and it extends its grammar from recent commits with an LLM
whose proposals a validation gate checks on the server. \tool found four previously
unknown bugs in \pg, two confirmed by committers and one already fixed, and
rediscovered four more. The grammar reaches 36.7\% of backend lines against
22.2\% for random mutation, but on a benchmark of 23 real bugs no
configuration found more than 2 of 20 in one hour, and the LLM adds features
rather than coverage. The precision of the oracles, not the reach of the
generator, decided how useful its findings were.
